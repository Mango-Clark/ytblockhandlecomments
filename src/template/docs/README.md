# Documentation

UI and README support ten locales. Choose a README language from the [project language links](../README.md). Wiki and changelog remain English/Korean; TODO, this index, and the review helper remain English.

English documents keep their existing paths. Non-English documents are grouped under `docs/<locale>/`; each locale folder contains its translated README, and `ko-kr/` also contains the Korean Wiki, changelog, and contribution guide.
