# 📌 YouTube Comment Blocker — v{{version}}

{{language_links}}

YouTubeの視聴ページとShortsで、チャンネルに基づいてコメントを非表示にするTampermonkeyスクリプトです。ハンドル・UCID・正規表現ルール、自動化、ローカル保存を管理できます。

## インストールと使い方

1. [Tampermonkey](https://www.tampermonkey.net/)をインストールします。
2. 下のraw URLを開くか、新しいスクリプトに`ytblockhandlecomments.js`を貼り付けます。
3. YouTube動画やShortsで投稿者のハンドルを右クリック、またはコメントの`⋯`メニューからチャンネルをブロック・解除します。
4. Tampermonkeyのスクリプトメニューからブロックリスト、設定、UI言語を開きます。

<https://raw.githubusercontent.com/Mango-Clark/ytblockhandlecomments/refs/heads/master/ytblockhandlecomments.js>

## 機能

- **ブロック：** 既定のハンドルルール、任意のUCIDペア、独立した正規表現、大小文字の区別に対応します。コメント投稿者への操作だけを拡張します。
- **コメントと自動化：** 非表示・灰色の代替表示・クリック再表示、自動低評価、正規表現の自動追加、本文・ハンドル・固定ラベルのキーワード操作に対応します。再利用されたノードも再処理します。
- **ブロックリスト：** 検索、種類・タグの絞り込み、選択、一括操作、JSON・テキストの入出力に対応します。正規表現の一致数・選択・展開・ページはリスト全体を作り直さず更新します。
- **設定：** 照合、コメント、自動化、ペアリング、APIキー、表示・テーマ、ログ・診断、リセットの8セクションです。入力と説明を縦に配置し、狭い画面ではメニューを上部に表示します。自動保存と既定値表示に対応します。
- **外観：** 文字・UIサイズ5段階、ライト・ダーク・システム・反転・YouTube・カスタムテーマです。YouTubeのネイティブな暗色状態と同期し、色はスクリプトUIだけに適用します。
- **性能：** 照合をキャッシュし、コメントホスト探索を制限します。1ページ100件、低負荷モードでは50件、小分け処理、検索遅延、1件ずつの手動ペアリングです。スキップした自動検索は再実行しません。
- **ログ：** ローカル・コンソール別出力、レベル・保持数・接頭辞・時刻書式・タイムゾーン、テスト出力・ダウンロード・確認付き消去、V0–V5の詳細度です。機密値を除去し、コメントごとの照合は記録しません。
- **状態：** 画面や言語の変更時も入力途中の値、検索・絞り込み・選択・ページ・スクロールを保持します。SPA移動では一時的な監視を初期化し、ダイアログはキーボードフォーカスを管理します。

## UCIDペアリング

1. ハンドルのブロックは即時適用します。既定では非同期でペアを作成し、失敗しても既存のブロックとリンクを保持します。
2. 作成は**handle → UCID**でペアと`id`ルールを保存します。更新は**UCID → 最新handle**でUCIDを保持し、名前変更時に古いハンドルを置換します。UCIDがなければ作成経路を使います。
3. 作成・更新・即時作成ごとにページのみ、公式APIのみ、ページ優先でAPI代替を選択します。ページ検索はキー不要、APIには保存済みキーが必要です。
4. UCID照合ではUCID検出とペアルールを有効にします。必要なルールができるまではハンドルモードを使ってください。キーワードによるペアは作成設定に従い、低負荷モードでも手動実行はできます。
5. 更新間隔または秒数（1秒以上）を選びます。既定はページ10分、API1週間です。全体更新は間隔に従い、選択項目は強制検索します。
6. ペア操作はブロックリストで実行します。状態、ハンドル別結果、絞り込み・並び順、失敗のコピー・出力、進捗、視聴ページの確認バナーを利用できます。APIテストにはクォータ案内があります。
7. ページでは対象チャンネル自身のメタデータを読みます。API更新には一致するUCIDと`@handle`形式のURLが必要です。欠落・競合・取消・検索失敗時は既存リンクを保持します。

## 言語

UIとREADMEは`en-us`, `ko-kr`, `ja-jp`, `de-de`, `zh-cn`, `zh-tw`, `fr-fr`, `pt-br`, `ru-ru`, `id-id`に対応します。設定 → 表示・テーマ、またはTampermonkeyの言語メニューで選択します。保存した選択を優先し、自動ではブラウザー設定から選び、未対応なら`en-us`を使います。

地域差は同じ対応言語に接続します（`en-GB` → `en-us`, `pt-PT` → `pt-br`）。中国語はHans/CN/SG → `zh-cn`、Hant/TW/HK/MO → `zh-tw`、`zh`のみは簡体字です。保存済み`en`/`ko`も有効です。Wikiと変更履歴は英語・韓国語、他のガイドは従来の言語です。

## 保存とプライバシー

- `blocked_v2`：`handle`・`id`（UCID）・`regex`ルールです。JSON・テキスト形式と`/pattern/flags`リテラルを維持します。
- `pair_meta_v1`はUCIDリンクと確認情報、`app_settings_v1`は設定、`youtube_data_api_v3_config`はキー・テスト・クォータ情報、`lang`は言語です。
- ペア情報とAPIキーはリストの入出力に含めません。キーはローカル保存し、公式API要求時だけ送信します。ログのダウンロードはUTC ISO時刻を使い、保存先はブラウザーが決めます。
- タブ同期はリビジョンと削除印で追加を統合し、削除済みルール・ログの復活を防ぎます。読み込み失敗時は書き込みを止め、保存失敗時は以前のデータを保持します。
- 旧リストは有効な現行データがない場合のみ移行します。UIDからUCIDへの移行でも保存キー・リビジョン・削除印・時刻を維持します。更新後は旧バージョンのタブを再読み込みしてください。
- データ形式、コンソール時刻トークン、実装の詳細は下のWikiで説明します。

## 既定値

- ハンドル照合、完全非表示、自動低評価オフ、即時ペアオン。新規導入の3検索設定はすべてページです。
- 文字・UIはレベル3、レベル2は従来サイズです。診断はV3。V0/V1は詳細なし、V2は1項目、V3は3、V4は6、V5は10です。
- 低負荷モードとログはオフです。キーワードは大小文字を区別せず、既定では本文を対象にし、有効化するまで操作しません。
- 更新時は既存設定と独自間隔を保持します。検索や言語の変更でルールや入力途中の値をリセットしません。

## 制限と注意

- ページ検索は非公式でHTML変更により失敗する場合があります。APIはクォータを使いますがUCID照合は保存後ローカルです。キーのテストには固定の公開チャンネルを使います。
- 古いハンドルは小文字保存の場合があり、再保存・追加後にのみ大小文字の一致を保証します。正規表現はハンドル、キーワードは選択した項目を対象にします。
- 正規表現の長さ・フラグ・構造を検証し、照合対象を128文字に制限します。コメント処理は対応する動画・Shorts内、ペアのバナーは視聴ページだけです。
- YouTube・APIの応答原文、ユーザー内容、チャンネルID、プロトコル、機械用ログは翻訳しません。埋め込みプレーヤーを除外し、指定のTampermonkey権限のみ使います。

## 開発と検証

- `dev`で`src/`のTypeScriptを編集します。番号は読み順で実行順はES importです。共通保存は`03a-gm-backed-store.ts`、管理UIは`12a`–`12e`です。
- 生成済みREADME・docsではなく`src/template/`を編集します。`npm run build`が全翻訳と圧縮版`ytblockhandlecomments.js`を一括生成し、Tampermonkeyはルートのスクリプトだけを読みます。
- UIとREADMEの10言語を揃えます。`en.ts`が型、`locales.ts`が言語名・パス・貢献者、`i18n-mason.toml`が範囲を管理します。置換値と機械用テキストを維持してください。
- `npm run verify`はlint、Markdown lint、型、決定的な`node:test`、ビルド、生成物確認を実行します。各コマンドは個別実行でき、明示的に省略した確認は報告します。
- ソースと生成物をConventional Commitで一緒にコミットし、独立レビューを受けます。明示的許可なしにバージョン変更・pushしません。リリースは`npm run bump:version -- <MAJOR.MINOR.PATCH>`です。

```sh
npm run lint
npm run lint:markdown
npm run typecheck
npm run build
npm run check:build
npm run verify
```

将来の任意ブラウザー検証は依存不要の検証と分離し、自動テストに実YouTubeセッションを要求しません。
